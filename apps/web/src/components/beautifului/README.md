# Beautiful UI adaptations

These local primitives adapt interaction and component source from
[Beautiful UI](https://www.beautifului.dev/) to Thinkfy's semantic design
tokens, accessibility requirements, localization boundaries, and existing
application contracts.

Original component source: Copyright (c) 2026 Shane Levine, MIT License.
See [LICENSE.md](./LICENSE.md).

The adaptations deliberately do not expose model chain-of-thought. Loading and
tool states communicate only user-safe progress already available to the UI.
